# MVC Project

Subject Course: COMP 019 Application Development and Emerging Technologies

## About

A web application built with ASP.NET Core MVC (.NET 10). It contains the profiles and portfolios of the members, built with C#, Razor, HTML, CSS, and Bootstrap. The project follows the Model-View-Controller pattern, which separates the data, the logic, and the design of each page. Each member developed their own page on a separate branch (feature).

## Branches

| Branch | Description |
|---|---|
| `main` | The stable, final version of the project. Only tested and approved work is merged here. |
| `dev` | The development branch where members' finished features are combined and tested together before release. |
| `release` | Prepares a version for submission or deployment. Only final fixes are made here. |
| `staging` | A pre-release copy used to check the whole website before it goes to `main`. |
| `test` | Used for testing and trying out changes without affecting the other branches. |
| `feature/gatmen-profile` | Alliah's branch, containing her student profile page and portfolio. |
| `feature/lapuz-profile` | Katrice's branch, containing her student profile page and portfolio. |
